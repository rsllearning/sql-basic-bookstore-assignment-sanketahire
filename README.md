# Online Bookstore Management System (SQL Basic Assignment)

## Overview
This repository contains the database implementation and SQL query solutions for the **SQL (Basic) Assignment**. The project models an online bookstore management system, covering relational schema design, data retrieval, multi-table joins, aggregate analytics, DML lifecycle management, and table constraints.

## Project Structure
- `bookstore_management.sql`: Master SQL script containing schema creation (DDL), sample seed data, and Tasks 1 through 21.
- `docs/`: Reference training material and assignment specification documents:
  - `docs/Training.Material.SQL (Basic).pdf`: Core SQL training material.
  - `docs/Training.Assignment.SQL (Basic).pdf`: Assignment instructions and task requirements.
- `screenshots/`: Visual execution evidence for required milestone tasks (Tasks 12, 15, and 21).
- `README.md`: Comprehensive documentation, relational schema overview, ER diagram, and step-by-step execution instructions.

## Development & Review Workflow
In accordance with professional engineering standards:
- The complete assignment implementation is developed on the dedicated feature branch: `feature/sql-basic-implementation`.
- Full task solutions, execution proofs, and expanded documentation are reviewed via a GitHub Pull Request (PR) targeting `main`.
